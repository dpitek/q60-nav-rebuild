Java 11 headless JRE — installation handled by scripts/install-jre-rootfs.sh
============================================================================

Run from the project root before packaging the rootfs image:

  ./scripts/install-jre-rootfs.sh

What it does:
  - Downloads openjdk-11-jre-headless (i386) from Debian Bullseye mirror
  - Extracts libz1 and libstdc++6 (i386) as JVM runtime dependencies
  - Extracts everything into rootfs/ via Docker (q60-toolchain image)
  - Java lands at: rootfs/usr/lib/jvm/java-11-openjdk-i386/
  - Symlink created: rootfs/usr/bin/java -> /usr/lib/jvm/java-11-openjdk-i386/bin/java

The S25-photon init script expects Java at /usr/bin/java (confirmed).
Without it, Photon is skipped gracefully and geocoder search is unavailable.

Estimated size impact: ~120-140MB in the rootfs image.
package-rootfs.sh will warn (but not fail) if /usr/bin/java is missing.
